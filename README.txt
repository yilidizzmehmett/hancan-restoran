HANCAN KEBAP DÖNER — SUPABASE BAĞLANTISI

1) supabase-config.js dosyasını aç.
2) SUPABASE_PROJE_URL_BURAYA yerine Supabase Proje URL'sini yaz.
3) SB_PUBLISHABLE_ANAHTAR_BURAYA yerine sb_publishable_ ile başlayan yayınlanabilir anahtarı yaz.
4) Secret veya service_role anahtarını kesinlikle kullanma.
5) Dosyaları GitHub deposunun ana klasörüne yükleyip eskilerle değiştir.

Menüdeki fiyatlar örnektir, gerçek fiyatlarla değiştirilmelidir. Bu sürüm siparişi Supabase'e eklemeyi dener ve WhatsApp'ı açar. Yönetici paneli henüz eklenmemiştir. Supabase tablosundaki siparişleri herkese açık SELECT politikasıyla açmayın.
